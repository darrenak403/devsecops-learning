# 🛡️ DevSecOps — 30 Days Learning Journey

Dự án tự học DevSecOps trong 30 ngày, sử dụng **Terraform** để tự động hoá hạ tầng trên **DigitalOcean**.

---

## 🎯 Mục tiêu

Sau 30 ngày, mình sẽ có thể:

- **Tự động hoá hạ tầng** — dùng Terraform tạo server, network, firewall thay vì click tay
- **Bảo mật từ đầu** — tích hợp security scan vào CI/CD, không để lộ secrets
- **Vận hành thực tế** — deploy ứng dụng với Docker, quản lý bằng Kubernetes cơ bản
- **Làm được portfolio** — có repo thực hành để show khi apply vị trí DevOps / Cloud Engineer

---

## 📦 Tech Stack

- **Terraform** — Infrastructure as Code
- **DigitalOcean** — Cloud Provider
- **GitHub Actions** — CI/CD
- **Docker / Kubernetes** — Container
